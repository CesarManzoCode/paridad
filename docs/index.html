paridad — API de Resend

Referencia de las 144 operaciones de la especificación OpenAPI fijada de Resend (OpenAPI 3.1.2, versión 1.5.1) en los SDKs de TypeScript (paridad-resend), Python (paridad_resend) y Go (github.com/CesarManzoCode/paridad/sdks/go) y en el CLI paridad. Generada por paridad desde ir/ir.json; no se edita a mano.

Configuración

Todos los ejemplos leen la clave de RESEND_API_KEY y la URL base de RESEND_BASE_URL (por defecto https://api.resend.com); el tiempo máximo de cada intento sale de RESEND_TIMEOUT_MS (por defecto 30000). Cada ejemplo es un programa completo que imprime la respuesta en JSON y termina con un código distinto de 0 si la API devuelve un error.
